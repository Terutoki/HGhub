## HGhubX 2.0.0

HGhubX 2.0 brings the HGhubX naming migration, resilient playback sources, shared mobile UI, and the iOS icon pipeline together in one release.

### Highlights

- **HGhubX migration**: renamed the application consistently, migrated legacy local data, and kept old environment variables compatible during upgrades.
- **Playback and networking**: restored source failover and manual source selection, kept source choices across reloads, routed Linux WebKit media directly when appropriate, and added custom mirrors plus per-app system/custom/direct proxy modes.
- **Diagnostics**: expanded network and playback diagnostics, separated DNS, TCP, proxy, and HTTP failures, and redacted proxy credentials from copied reports.
- **Cross-platform UI**: refreshed the glass materials, adaptive light/dark appearance, spring interactions, shared switches, category and ranking layouts, profile tab alignment, and cover metadata. Cover scores now stay in the cover's top-right corner across desktop, Android, and iOS.
- **iOS packaging**: generated the custom HGhubX icon from a full-bleed square source, let iOS apply its rounded mask, verified all 18 icon slots, and removed the default Tauri icon from generated IPA builds.

### Compatibility

- Existing HGhub/HGhubX local data is migrated on first launch.
- Legacy environment variables remain accepted while `HGHUBX_*` names are preferred.
- iOS package is an unsigned IPA and must be signed with an Apple account before installation.

### Build artifacts

The release workflow builds and uploads:

- Linux amd64 `.deb`
- Android arm64, arm, and x86_64 APKs
- Windows x64 installer and portable ZIP
- macOS universal `.dmg`
- iOS unsigned `.ipa`

### Verification

- Frontend and Rust CI passed on the release ancestry.
- Targeted mobile UI, score badge positioning, icon generation, and icon catalog tests passed.
- The release tag is signed with SSH and verified by GitHub.
